# Password Strength Checker

## Description
This is a beginner cybersecurity project that checks the strength of a password based on different requirements.

The program checks whether a password contains different types of characters and gives the user feedback about its strength.

## Features
- Checks password length
- Checks for uppercase letters
- Checks for lowercase letters
- Checks for numbers
- Checks for special characters
- Gives a password strength result

## Technologies Used
C++

## How to Run
1. Open the project in VS Code.
2. Compile the C++ program.
3. Run the program.
4. Enter a password when prompted.
